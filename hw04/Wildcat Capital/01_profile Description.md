Create a script in the "scripts" folder in hw04\Wildcat Capital called "01_profile.py". This program should work on any table fed into the program. The program should report for every column in the csv: null/blank count, distinct count, dominant value shapes, share of values that fail to parse as the expected type, whitespace problems, mixed formats, and numeric min/max. There will be checks in four groups. Column Level - type, allowed values, ranges, key uniquness. Single-table rules - duplicates, near-duplicates, values that contradict other columns of the same row. Referential integrity - every foreign key must point to an existing primary key. Cross-table business rules - facts that disagree with dimensions or with each other. Each finding should be classified as an "Error" - wrong, or will break a join or calculation; "Warn" - probably wrong, but should investigate; and "Info" - worth knowing. Save this report to a folder called "reports" under "profile_raw.csv" and dq_summary_raw.csv.
